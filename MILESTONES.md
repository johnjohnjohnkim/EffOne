# Milestones: EffOne

Goal: predict current-season F1 qualifying and races (win, podium and top-10 probabilities) and the drivers' and constructors' championships, served through a web app and updated as new sessions finish.
Out of scope: pit-stop strategy and safety-car prediction; training on pre-2018 data; full model retraining on every refresh. Full design and decisions are in `HANDOFF.md`; rules for agents are in `AGENTS.md`.

Report: Added `ml/evaluation/` (`data.py`, `splits.py`, `metrics.py`, `baselines.py`, `harness.py`, `__main__.py`) and `tests/test_evaluation.py` (8 tests, all pass; `ruff check` clean).
- Design: a model gets only pre-race columns for the race plus the results of every earlier race (`history`), so it cannot see outcomes or future races by construction; tests assert this. Models implement `fit(train)` and `predict_race(history, race)`, so the Milestone 4 models plug into the same harness. Scores are "lower = better finish". Pit-lane or missing grid slots are placed at the back of the grid.
- Locked final test season is 2025 (`splits.LOCKED_SEASON`); it is skipped unless `--allow-locked` / `allow_locked=True`. It has not been evaluated.
- Verified: `python -m uv run python -m ml.evaluation` run twice gave byte-identical `data/reports/leaderboard.csv`. On the 99 races ingested so far (test seasons 2019 to 2023, 2018 is training-only): grid = finish: Spearman 0.602, winner accuracy 0.515, podium overlap 0.690, top-10 overlap 0.752; previous race = finish: 0.444, 0.394, 0.545, 0.682.
- Caveats: the backfill is incomplete (2023 has 17 rounds so far; 2024 and 2025 not ingested; 2018 R14 Race is missing), so numbers will shift when the data is complete and the harness should be rerun. Log loss and calibration are not included yet (they need probabilities; Milestone 5). Fixed new ruff default-rule findings in `ml/ingest` along the way (bound loop variables with `functools.partial`, UTC dates); behaviour is unchanged.
